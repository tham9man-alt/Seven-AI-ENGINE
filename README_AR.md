# SEVEN AI ENGINE

مشروع استوديو صور عربي يعمل على **Cloudflare Workers + Workers Static Assets + D1**.

## البنية الحالية

- `worker.js`: واجهات الحسابات والجلسات واستعادة كلمة المرور والتوليد.
- `public/`: واجهة RTL وملفات PWA.
- `migrations/`: ترحيلات قاعدة بيانات D1.
- `wrangler.jsonc`: إعداد Worker الاختباري `seven-ai-engine-test` وربط قاعدة `sevenaiusers-test`.

## المتطلبات

- Node.js 18 أو أحدث.
- حساب Cloudflare وصلاحية على Worker وقاعدة الاختبار عند الحاجة.
- متغير سري `OPENAI_API_KEY` في إعدادات Worker الاختباري.
- `RESEND_API_KEY` لإرسال رسائل استعادة كلمة المرور.
- يمكن تحديد `IMAGE_MODEL` كمتغير بيئة، والقيمة الافتراضية الحالية في الكود هي `gpt-image-2.5-flare`.

لا تضع مفاتيح API داخل ملفات المستودع أو مجلد `public`.

## التطوير المحلي

```bash
npm run dev
```

أو استخدم Wrangler مباشرة:

```bash
npx wrangler dev --config wrangler.jsonc
```

فحص بناء دون نشر:

```bash
npm run check
```

## قاعدة البيانات

تسلسل migrations الحالي:

1. `0000_initial_schema.sql`
2. `0001_password_recovery.sql`
3. `0002_credits_and_rate_limits.sql`

الترحيل الثالث يضيف رصيدًا افتراضيًا قدره صفر للحسابات الموجودة، ويمنح **10 نقاط للحساب الجديد فقط** عند التسجيل. كما ينشئ سجل حركات الرصيد وجدول حدود محاولات المصادقة.

قبل تطبيق الترحيلات على قاعدة الاختبار، راجع اسم قاعدة البيانات ومعرّفها في `wrangler.jsonc`. لا تطبق هذه الترحيلات على قاعدة الإنتاج.

لتطبيق الترحيلات على قاعدة الاختبار البعيدة فقط، وبعد الموافقة الصريحة:

```bash
npx wrangler d1 migrations apply sevenaiusers-test --remote --config wrangler.jsonc
```

لا تنفذ هذا الأمر على الإنتاج.

## نظام النقاط

- يحصل الحساب الجديد على 10 نقاط داخلية.
- تخصم نقطة واحدة عند نجاح طلب إنشاء صورة.
- إذا فشل مزود الصور، يعيد الخادم النقطة.
- يمنع الخادم بدء التوليد عندما يكون الرصيد صفرًا.
- يسجل الخادم عمليات الخصم والاسترداد في `credit_transactions`.

هذه النقاط داخل التطبيق وليست رصيدًا أو أرصدة OpenAI API.

## التوليد

يدعم الخادم المقاسات:

- `1024x1024`
- `1024x1536`
- `1536x1024`

وخيارات الأسلوب الموجودة في الواجهة. تُرسل تعليمات الأسلوب ضمن وصف الصورة، بينما يرسل المقاس إلى Images API. جودة التوليد مضبوطة حاليًا على `high`.

## الأمان

- كلمات المرور مخزنة باستخدام PBKDF2-SHA256.
- الجلسات تستخدم Cookie من نوع HttpOnly وSecure وSameSite=Lax.
- رموز الجلسات واستعادة كلمة المرور مخزنة كـ SHA-256 hashes.
- توجد حدود أولية للمحاولات حسب عنوان IP في التسجيل والدخول واستعادة الحساب.
- لا يزال يلزم اختبار أمني وتشغيلي شامل قبل اعتبار النسخة جاهزة للإنتاج.

## النشر

هذا المستودع مضبوط لبيئة الاختبار. لا تستخدم `wrangler deploy` إلا بعد مراجعة البيئة المستهدفة والموافقة الصريحة. لا تنشر إلى `main` أو الإنتاج ضمن خطوات التطوير الاعتيادية.
