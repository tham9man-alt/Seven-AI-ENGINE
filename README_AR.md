# SEVEN AI ENGINE — النسخة التأسيسية

هذه نسخة أولية قابلة للنشر كتطبيق ويب تقدمي (PWA)، ويمكن إضافتها إلى الشاشة الرئيسية لهاتف Android.

## ما الموجود؟
- واجهة عربية باتجاه RTL.
- اختيار أسلوب الصورة وأبعادها.
- منطقة معاينة وزر تنزيل.
- ملف manifest وService Worker للتثبيت وتجهيز الواجهة للعمل عند ضعف الاتصال.
- نقطة خادم `/api/generate` حتى لا نضع مفاتيح الخدمات السرية داخل الهاتف.

## مهم
هذه النسخة **واجهة تأسيسية وليست محرك توليد مكتملًا بعد**. نقطة `/api/generate` ترجع رسالة توضح أن مزوّد الصور لم يُربط بعد. لا يوجد مفتاح API مضمّن في الملفات.

## النشر على Cloudflare Pages
1. ارفع محتويات هذا المجلد إلى مستودع Git.
2. أنشئ مشروع Pages واربطه بالمستودع.
3. اجعل مجلد الملفات الثابتة هو `public`، واترك مجلد `functions` في جذر المشروع.
4. بعد النشر افتح رابط الموقع على هاتف Android، ومن قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

## الخطوة التالية
اختيار مزوّد توليد الصور وربط API الخاص به داخل `functions/api/generate.js` باستخدام متغيرات سرية في إعدادات Cloudflare. لا تضع أي مفتاح سري في ملفات `public`.
